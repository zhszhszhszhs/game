# 本次修改与训练结果

日期：2026-09-30。实验：`dqn_revised_500k`。

## 修改内容

- **修复丢球后停滞**：统一环境包装器在丢失生命后自动执行 FIRE，避免贪心策略一直等待发球。保留原生奖励和完整游戏 episode，训练、评估、网页共用相同规则。
- **调整训练配置**：延长探索、扩大经验池、提高目标网络同步频率；保留原配置 `configs/dqn_original.yaml`。算法仍为 SB3 DQN + CnnPolicy，没有增加奖励塑形或其它算法。
- **完善续训与保存**：支持重新计步和探索日程；模型不含 replay 时重新收集经验；每 50k 步保存模型，正常结束或可捕获中断时保存经验池，支持 SIGTERM 中断保存。
- **增加运行监控**：新增 `src/launch_training.py` 后台启动及状态查询；`src/callbacks.py` 记录运行状态、评估耗时、自动发球次数和超时率；JSON 状态文件采用原子替换。
- **完善评估与演示**：开发评估每次重置相同种子；独立评估 CSV 增加超时标记和剩余生命；现有网页显示自动发球动作并补充规则说明。
- **升级游戏界面**：重新布局画面与状态面板，默认推荐最佳模型，增加最近 10 局成绩、播放速度、全屏和快捷键；采集真实中间帧并用连续画面流替代逐张轮询，原速目标 60 帧/秒，不改变模型决策和训练规则。
- **补充验证、精简文档**：增加丢失生命后自动发球的回归测试；将运行说明集中到 README，删除重复的实验计划和训练状态文档。

## 训练设置

从旧实验 150k 最佳模型加载网络和优化器，新阶段计数从 0 开始，额外训练 500k 决策步。旧经验池未保存，因此先在修正后的环境中收集新经验；这不是原训练的无缝恢复。

| 参数 | 原配置 | 本次配置 |
|---|---:|---:|
| 经验池容量 | 50k | 100k |
| 开始梯度更新前的经验收集 | 20k | 50k |
| ε 降至 0.05 的步数 | 100k | 300k |
| Target Network 同步间隔 | 10k | 1k |
| Checkpoint 间隔 | 100k | 50k |

其余主要参数：seed=42、学习率 1e-4、batch size=32、gamma=0.99，每 4 步进行 1 次梯度更新。状态为 4×84×84 图像，ALE 与 wrapper 不重复跳帧。

## 训练结果

本轮状态为 **completed**，在 `cuda:0` 上完成 500,000 步，耗时 **45.5 分钟**，新增 **112,500 次梯度更新**，完成 **1,265 局**训练。最初 100 局训练平均得分 **1.42**，最后 100 局为 **24.41**。

每 50k 步进行 5 局贪心开发评估，结果如下：

| 新阶段步数 | 平均得分 |
|---|---:|
| 50k | 3.4 |
| 100k | 10.0 |
| 150k | 13.0 |
| 200k | 17.8 |
| 250k | 29.2 |
| 300k | 19.6 |
| 350k | 21.0 |
| 400k | 30.6 |
| 450k | 29.8 |
| **500k** | **31.4** |

最佳模型来自 **500k** 节点。该次 5 局得分为 **31、31、42、31、22**，总体标准差 **6.34**，平均长度 **896.2 个决策步**，超时率 **0**。学习趋势总体向上，但中途存在波动。

这些是用于选择 checkpoint 的少量固定种子开发评估，不能代替独立测试，也不能据此证明稳定超过随机策略。旧随机基线使用修复前的发球规则，需重新测量后比较。独立 50 局测试、报告绘图和视频录制按要求暂未执行。
